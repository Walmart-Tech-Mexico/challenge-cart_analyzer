# Analizador de carrito

**Nivel:** Intermedio

## Descripción
Detectar patrones de abandono de carrito en distintas sesiones.

## Objetivo
Implementa una solución en Java que cumpla con la lógica descrita. Usa la plantilla `Main.java` para comenzar.

## Cómo empezar
1. Clona este repositorio.
2. Dirígete a la carpeta `Analizador_de_carrito`.
3. Abre `Main.java` y escribe tu solución.
4. ¡Comparte tu solución con la comunidad!
